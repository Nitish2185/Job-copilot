# Permissions

Every permission the extension requests and why. Store reviewers read this; keep it current.

| Optional: `https://api.groq.com/*`, `https://openrouter.ai/*`, `http://localhost/*`, `http://127.0.0.1/*`, `https://*/*`                                                                                                                                           | Requested at runtime, one origin at a time, only when the user picks Groq, OpenRouter, a local Ollama or a custom AI endpoint. Firefox lists them under `optional_permissions`.                                                                                                                                                                                          |

Opening the dashboard on install and from the toolbar button (`tabs.create`) needs no permission.
Scripts injected on demand (the generic Autofill script) run through `activeTab` only: the build
strips the every-site match WXT would otherwise add to the required hosts, and
`scripts/check-release-build.mjs` fails CI if `https://*/*`, `http://*/*` or `<all_urls>` ever
appears as a required permission.
End-to-end test builds (`JOB_COPILOT_E2E=1`) add `http://localhost/*` and `http://127.0.0.1/*` for local
fixture servers; release builds never include them.

## Never requested

`cookies`, blocking `webRequest`, `debugger`, `history`, `management`, and `<all_urls>` as a
required permission.

## Content security policy

Extension pages use `script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`. The only
addition to the browser default is `'wasm-unsafe-eval'`, which lets the bundled resume PDF
layout engine (WebAssembly) run. JavaScript `eval` stays blocked and no remote code is loaded.
